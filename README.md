# 🎹 Virtual Piano

A modern browser-based virtual piano with keyboard controls, sound synthesis, meme soundboard mode, built-in songs, and dynamic themes.

## 🌐 Live Demo

https://virpiano.netlify.app/

---

## ✨ Features

- 🎹 Play piano directly in browser
- ⌨️ Keyboard shortcut support
- 🔊 Adjustable volume control
- 🎛️ Multiple waveform types
- 🎼 Built-in song player
- 🤣 Fun Meme Soundboard Mode
- 🌈 Dynamic theme switcher
- ⚡ Smooth low-latency audio
- 📱 Responsive UI

## 🚀 Run Locally

Clone the project:

```bash
git clone https://github.com/happymite/virtual-piano-.git
```

Open the folder:

```bash
cd virtual-piano-
```

Run with Live Server or open `index.html` in browser.
